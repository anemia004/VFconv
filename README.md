# VFconv

A modern Android video converter with a liquid glass UI and animated gradient background. Converts videos using Media3 Transformer (hardware-accelerated, no FFmpeg binaries).

## Features

- Select video via Storage Access Framework
- Convert to MP4, MKV, or WebM
- Choose video codec: H.264, H.265, VP9, AV1
- Adjust resolution and bitrate
- Progress bar with cancel option
- Glassmorphism design
